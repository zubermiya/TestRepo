# Troubleshooting Guide

## Stuck on 'Analyzing Media...'?

**Quick Fixes:**
1. Wait 30 seconds (auto-timeout)
2. Try smaller file (< 5MB)
3. Refresh page and retry
4. Use JPG/PNG for images, MP4 for videos

**If still stuck:**
- Press F12, check Console for errors
- Restart app: Ctrl+C then 'python app.py'
- Run 'python test_system.py' to verify system

## Performance Issues?
- Use smaller images
- Try JPEG format
- Close other apps to free memory

## Upload Errors?  
- Check file extension (.jpg, .png, .mp4)
- File must be < 100MB
- Ensure file isn't corrupted

## Need Help?
Run: python test_system.py
